# mdcheck - Markdown 规范检查工具\n\n一个用于检查 Markdown 文件是否规范的 Go CLI 工具，专门用于防止 AI 生成的文档导致渲染错乱。\n\n## 功能特性\n\n- ✅ **未闭合代码块检查** - 检测未闭合的 ``` 代码块\n- ✅ **空标题检查** - 检测没有内容的标题\n- ✅ **重复标题检查** - 检测重复的标题文本\n- ✅ **链接格式检查** - 检测可能无效的链接\n- ✅ **表格对齐检查** - 检测表格列数不一致\n- ✅ **列表缩进检查** - 检测列表项缩进不一致\n- ✅ **代码块语言检查** - 检测未知的代码块语言标识\n\n## 安装\n\n```bash\ngo build -o mdcheck .\n```\n\n或者直接使用已编译的二进制文件。\n\n## 使用方法\n\n### 检查单个文件\n\n```bash\nmdcheck README.md\n```\n\n### 检查多个文件\n\n```bash\nmdcheck docs/*.md\n```\n\n### 检查指定文件\n\n```bash\nmdcheck -f document.md\n```\n\n### 从标准输入读取\n\n```bash\ncat file.md | mdcheck\n```\n\n## 使用示例\n\n### 检测未闭合的代码块\n\n```markdown\n# 测试文档\n\n```go\nfunc main() {\n    fmt.Println("Hello")\n```\n```\n\n输出：\n```\n发现 1 个问题\n\n:\n  4:1 未闭合的代码块，未找到对应的结束标记 ```\n    → 添加 ``` 结束标记，或检查是否意外在代码内容中包含了 ```\n```\n\n### 检测重复的标题\n\n```markdown\n# 测试文档\n\n# 重复的标题\n\n# 重复的标题\n```\n\n输出：\n```\n发现 1 个问题\n\n:\n  4:1 重复的标题：'重复的标题'\n    → 使用更具体的标题名称，或修改其中一个标题\n```\n\n### 检测空标题\n\n```markdown\n# 测试文档\n\n#\n\n## 标题\n```\n\n输出：\n```\n发现 1 个问题\n\n:\n  3:1 空标题：标题后没有内容\n    → 在标题后添加内容，或删除空标题\n```\n\n## 输出格式\n\n工具会输出发现的问题数量和详细信息，包括：\n- 问题所在的行号\n- 问题描述\n- 修复建议（如适用）\n\n## 技术细节\n\n- 使用 Go 编写，跨平台兼容\n- 轻量级，无外部依赖\n- 支持多种 Markdown 扩展语法\n\n## 许可证\n\nMIT License\n
