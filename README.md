# mdcheck - Markdown 规范检查工具

一个用于检查 Markdown 文件是否规范的 Go CLI 工具，专门用于防止 AI 生成的文档导致渲染错乱。

## 功能特性

- ✅ **未闭合代码块检查** - 检测未闭合的 ``` 代码块
- ✅ **空标题检查** - 检测没有内容的标题
- ✅ **重复标题检查** - 检测重复的标题文本
- ✅ **链接格式检查** - 检测可能无效的链接
- ✅ **表格对齐检查** - 检测表格列数不一致
- ✅ **列表缩进检查** - 检测列表项缩进不一致
- ✅ **代码块语言检查** - 检测未知的代码块语言标识

## 安装

```bash
go build -o mdcheck .
```

或者直接使用已编译的二进制文件。

## 使用方法

### 检查单个文件

```bash
mdcheck README.md
```

### 检查多个文件

```bash
mdcheck docs/*.md
```

### 检查指定文件

```bash
mdcheck -f document.md
```

### 从标准输入读取

```bash
cat file.md | mdcheck
```

## 输出格式

工具会输出发现的问题数量和详细信息，包括：
- 问题所在的行号
- 问题描述
- 修复建议（如适用）

## 技术细节

- 使用 Go 编写，跨平台兼容
- 轻量级，无外部依赖
- 支持多种 Markdown 扩展语法
