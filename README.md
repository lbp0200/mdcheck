# mdcheck - Markdown 规范检查工具

一个用于检查 Markdown 文件是否规范的 Go CLI 工具，专门用于防止 AI 生成的文档导致渲染错乱。

## 功能特性

- ✅ **未闭合代码块检查** — 检测未闭合的 ` ``` ` 代码块
- ✅ **代码块内意外标记检查** — 检测代码块内容中出现的 ` ``` `
- ✅ **空标题检查** — 检测没有内容的标题 `#`
- ✅ **重复标题检查** — 检测重复的标题文本
- ✅ **链接格式检查** — 检测可能无效的链接 URL
- ✅ **图片 Alt 文本检查** — 检测 `![](url)` 缺少替代文本
- ✅ **表格对齐检查** — 检测表格列数不一致
- ✅ **代码块语言检查** — 检测未知的代码块语言标识
- ✅ **列表缩进检查** — 检测列表项缩进不一致
- ✅ **列表标记一致性检查** — 检测 `-` 和 `*` 混用
- ✅ **连续空行检查** — 检测多余的空行
- ✅ **行尾空格检查** — 检测行尾多余的空格
- ✅ **超长行检查** — 检测超过 120 字符的行（跳过代码块）
- ✅ **文件结尾换行符检查** — 检测文件末尾是否缺少换行符
- ✅ **引用式链接检查** — 检测 `[text][ref]` 但缺少 `[ref]: url` 定义
- ✅ **引用式图片检查** — 检测 `![][ref]` 缺少替代文本
- ✅ **标题级别跳跃检查** — 检测 `# H1` → `### H3` 跳过了 H2
- ✅ **制表符检查** — 检测文件中是否混入 Tab 制表符（跳过代码块）
- ✅ **标题层级上限检查** — 检测超过 H6（7个及以上 `#`）的标题
- ✅ **裸 URL 检查** — 检测 `https://...` 未包裹在 `[text](url)` 或 `<url>` 中（跳过代码块和引用定义）

## 安装

```bash
go build -o mdcheck .
```

或者直接使用已编译的二进制文件。

## 使用方法

### 检查单个文件

```bash
mdcheck README.md
```

### 检查多个文件

```bash
mdcheck docs/*.md
```

### 检查指定文件

```bash
mdcheck -f document.md
```

### 从标准输入读取

```bash
cat file.md | mdcheck
```

### JSON 输出（适合 CI 集成）

```bash
mdcheck --json *.md
```

通过时输出 `[]`，失败时输出问题数组：
```json
[
  {
    "file": "README.md",
    "line": 5,
    "column": 1,
    "message": "空标题：标题后没有内容",
    "suggestion": "在标题后添加内容，或删除空标题"
  }
]
```

### 超长行阈值

```bash
mdcheck --max-line-length 100 *.md
```

默认 120 字符。

### 自动修复

```bash
mdcheck --fix README.md
```

自动修复以下问题后重新检查：
- 删除行尾多余的空格
- 删除连续空行（代码块内保留）
- 添加文件末尾缺失的换行符
- 统一换行符为 LF

### 检查换行符

自动处理 `\r\n`（Windows）和 `\n`（Unix）换行符。

## 输出格式

工具会输出发现的问题数量和详细信息，包括：
- 问题所在的行号和列号
- 问题描述
- 修复建议（如适用）
